上周我只学了 C 语言，却误以为这是 C++，好尴尬。这周我去了解了 C++，真正让我苦恼的却是二进制、八进制、十六进制之间的转化，但这跟 C++ 没有太大的关系，我的学习成果如下：

输入与输出

cin 和 cout 是最简单的输入与输出方式了，但之前没怎么用过，总是会把 < 的朝向搞混。除此之外还踩过”变量不能加引号”的坑。

关于 setw 和 setprecision

之前用 setw() 或者 setprecision() 的时候，不知道它是 <iomanip> 头文件里的，这就导致做作业时 PTA 报了很多次编译错误。

说到
setprecision()，刚开始输出时我发现了一件神奇的事情，它对后面的影响貌似是永久的。比如这段我保留了两位小数，那么下一次输出数字的时候还是会保留两位小数，如果想保留更多就要重新弄一个setprecision(),当然千万不要忘了要在前面加一个fixed，不然保留的就不是小数了。

自从知道
了setprecision()对后面有永久性的效果之后我就在想stew（）会不会有同样的效果，但事实证明他是没有的。

double和float的区别

自从学习了
c语言这个问题就一直在困扰我，这几天我终于把精力分散到了这上面。

float a = 3.14f 明确告诉编译器这是float
float b = 3.14; 能跑，但其实是 double → float，会丢精度、可能报警告

精度差异 float f = 0.123456789f; `` double d = 0.123456789012345;

但一般都会去用double吧。

自增自减

这个是目前为止我最想了解的，我甚至把相关代码放在了桌面上。

#include <stdio.h> int main() { int a=9,b=1,c,d; c=++a; //相当于c=a+1,但是++a是前置，相当于先把a+1，在给c赋值，此时a=10=c，但a++是后置相当于先把c赋值再加一后给a赋值此时c=9 a=10 d=b--; //相当于b=a-1，自减同上 printf("%d %d %d %d",a,b,c,d); return 0; }

就比如这串代码，由于只是看书上写的，但是写的不是很细，这就导致了我自己一直再一遍一遍试错，到最后实在受不了了便和我的workbuddy交流了一下才知道有前置和后置两个东西。
