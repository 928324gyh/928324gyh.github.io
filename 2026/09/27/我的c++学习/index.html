这是我的c++学习过程，由于这几天军训，留给我学习的时间很紧凑，就先说一下对于#include <stdio.h>的理解吧。
我一开始以为这就是一个固定公式化的东西，没有什么特殊含义，但是当我更深入了解c++一点以后，我发现并不是的，我就开始搜索它的含义，发现它其实就是告诉编译器把输入输出的头文件拿过来用，他的里面本来就放好了很多函数声明。
比如printf（）是打印后方括号内的进行输出。
而scanf（）是给量赋予一个自己想赋予的值，但是我总会把这个符号&忘掉
putchar（）虽然我用的比较少，但是我知道它只能输出单个字符，但是单个字符会依次排列。
当然如果提到scanf就不得不提到%d、%f、%c了，%d这个占位符是代表整数，%c是代表字符，最让我吃瘪的是这个%f，之前用这个的时候题目让输出3.14，而我无论怎么输出都是3.140000，后来了解了一下发现只打%f的话是默认保留6位小数，如果我想保留两位小数我得打%2f，%nf就是保留几位小数。
再聊一下if以及else吧
if - else 讲解
if 翻译是如果，else 翻译是否则。我拿这道题举例
if(6%2 ==0)
{
printf(“A”);
}
else
{
printf(“B”);
｝
这道题问的是最后会输出什么，6%2的含义是6/2的余数，它的余数是0，那么0=0，if括号里的内容是成立的，他就会输出“A”。
这周我学的最后一个内容就是switch了，在学习了前面的内容之后在去学习其他的就比较好理解了，这道例题是输入1，输出Monday，但要求有星期一到星期日，这个时候就要用到switch了。
#include <stdio.h>
int main()
{
int n;
scanf(“%d”,&n);
switch(n)
{
case 1:printf(“Monday”);break;
case 2:printf(“Tuesday”);break;
case 3:printf(“Wednesday”);break;
case 4:printf(“Thursday”);break;
case 5:printf(“Friday”);break;
case 6:printf(“Saturday”);break;
case 7:printf(“Sunday”);break;
}
return 0;
}
一定不要落掉break啊，不然命令会继续执行下去的。
